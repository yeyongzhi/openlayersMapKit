# Map

> 稳定性：`stable-beta`

地图门面类，聚合视图、图层、交互、控件与弹窗，是整个 SDK 的主入口。

## 引入

```ts
import { Map } from 'omap'
```

源码：`src/module/core/Map/index.ts`

## 说明与注意点

- 构造第一个参数为挂载元素（DOM 元素或选择器），第二个为地图选项；未显式指定的选项会与默认配置合并。
- 图层、交互、控件、弹窗统一通过 `add*` / `remove*` 方法管理，不建议直接操作底层 OpenLayers 实例。
- `dispose()` 永久释放地图及其挂载资源，重复调用安全；释放后实例不可再使用，`isDisposed()` 可查询状态。
- `remove()` 只解除挂载，对象仍可再次挂到新的目标上。

## 示例

```ts
const map = new Map('#map', {
  center: [116.397, 39.909],
  zoom: 12
})

map.addLayer(
  new XYZLayer({
    source: new XYZSource({ url: 'https://example.com/{z}/{x}/{y}.png' })
  })
)

// 组件卸载时
map.dispose()
```
