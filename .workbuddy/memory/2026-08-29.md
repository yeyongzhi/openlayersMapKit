### 实现要点（踩坑记录）

- **导出发现**：`export { default as X } from '...'`、无 from 的 `export { A, B }`（需先建 import 名→路径映射）、`export * from './dir/index'`（递归要传绝对路径，用 `path.relative` 会丢基准）。
- **const 枚举**（DrawMode / MeasureMode / PopupPositioning 等）不是类：`as const` 会被包成 AsExpression，需 `ts.isAsExpression` 逐层 unwrap；重命名导出（OMapFormatType → FormatType）要用 **local 原名**去定位声明。
- **重载**：存在纯声明重载时，实现签名必须过滤（`member.body && overloadNames.has(name)`），否则文档会出现 `idOrOptions?` 这种内部实现签名。
- **转义只做一次**：签名里的 `|` 只在写表格时由 `escapeCell` 转义，签名生成阶段不要预先转义，否则出现 `\\|`。
- **可选参数**的 `| undefined` 冗余，生成时正则去掉；构造签名用 `TypeFormatFlags.NoTruncation` 避免 `Partial<...>` 被截断。
- **别名导出**（`export const LngLat = Lnglat`）：页面以导出名呈现并标注实现类名，构造签名同步替换类名。
- **包的真实 name 是 `omap`**，不是 `openlayers-map-kit`——首版全部页面导入语句写错，已全量修正。写文档前先看 `package.json`。
- 全仓 `prettier --check .` 有 **260 个存量文件不合规**（含 tests/ 与配置文件，prettier 迁移本身是计划内待办），只对新改文件跑 `--write`，不要全仓格式化制造巨型 diff。
